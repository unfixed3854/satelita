# Security policy

## Supported versions

Satelita is pre-1.0 software. Security fixes target the latest release and the
current `main` branch; older versions are not maintained.

## Reporting a vulnerability

Please do not disclose a suspected vulnerability in a public issue. Use
[GitHub's private vulnerability-reporting form](https://github.com/unfixed3854/satelita/security/advisories/new)
and include:

- the affected version or commit;
- the operating system and relevant hardware;
- steps to reproduce the issue;
- the expected and observed impact; and
- any suggested mitigation, if known.

Reports will be reviewed privately. A fix and disclosure timeline will be
coordinated after the report has been reproduced and its impact assessed.
